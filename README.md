# UNSAID

> A privacy-first mental health companion for teenagers and young adults.

UNSAID is a web + mobile platform that helps young people **express → regulate → understand → rehearse → connect** to real-world support — without turning an LLM into a fake therapist.

**North-star principle:** Make the user more capable of handling life *outside* the app — not more dependent on the app to feel okay.
